# ⏱️ Stopwatch – Web Application

A simple and interactive **Stopwatch** built using **HTML**, **CSS**, and **JavaScript**. Features include lap tracking, start/stop functionality, and a visually appealing design with a background image.

## 🚀 Features

- **Start/Stop Button:** Toggles the stopwatch.
- **Lap Button:** Records the current time as a lap.
- **Reset Button:** Resets the stopwatch and clears the lap history.
- **Time Display:** Displays hours, minutes, seconds, and milliseconds.
- **Lap History:** Keeps track of each lap taken during the session.

## 🛠️ Technologies Used

- **HTML5** – Structure and layout.
- **CSS3** – Styling, including background image and button design.
- **JavaScript** – Stopwatch logic and time formatting.

## 📁 How to Use

1. Clone or download the project folder.
2. Open the `index.html` file in your browser.
3. Use the **Start** button to begin timing.
4. Press **Lap** to record each lap.
5. Press **Reset** to reset the stopwatch and lap history.

## 🔧 Customization Ideas

- Change the background image (`stopwatch.png`) to your preferred design.
- Add a **Pause** feature to temporarily stop the stopwatch without resetting.
- Enhance styling with CSS animations for better user experience.
